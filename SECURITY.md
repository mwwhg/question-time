# Security

## Reporting a vulnerability

Please report it privately through GitHub: open the [Security tab](https://github.com/mwwhg/question-time/security/advisories/new) and choose "Report a vulnerability". Do not open a public issue.

Say what you found, where, and how to reproduce it. You will get a reply within 7 days.

## Scope

This repository is an offline pipeline and a static site with no server code, accounts or user data. In scope: the code here, the published site, and anything in the git history that should not be public.

A reading you think is wrong is not a security issue. See "Found a mistake" in the [README](README.md).
